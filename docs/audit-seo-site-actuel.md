# Audit SEO du site actuel

Audit réalisé sur le site de 2019, avant la refonte. Il sert à décider quelles pages on garde.

## Constat

- 38 pages indexées, dont 21 sans visite sur les 12 derniers mois.
- Pas de balise `description` sur 30 pages, titres dupliqués sur 9 pages.
- Temps de chargement moyen sur mobile : 6,8 s (cible : moins de 2,5 s).
- Aucune donnée structurée, pas de plan du site envoyé à la Search Console.
- Le formulaire de contact est la seule conversion mesurée : 0,4 % des visites.

## Pages à garder

| Page actuelle | Visites / mois | Décision |
| --- | --- | --- |
| /accueil | 1 240 | Garder, réécrire (voir la maquette d'accueil) |
| /services/sites-vitrines | 410 | Garder, devient une page d'offre |
| /services/applications-web | 360 | Garder, devient une page d'offre |
| /references | 290 | Fusionner dans les études de cas |
| /blog/2020-tendances | 12 | Supprimer, redirection vers l'accueil |

## Priorités

1. Une redirection 301 pour chaque page supprimée.
2. Un titre et une description uniques par page.
3. Un plan du site XML et la déclaration dans la Search Console.
4. Alléger les images, première cause de lenteur.

## Suite

Les décisions alimentent la nouvelle arborescence (SITEWEB-2).
